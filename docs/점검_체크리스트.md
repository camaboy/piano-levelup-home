# v1.0 통합 시험판 — 아이패드 점검 체크리스트

시험 조건: 아이패드 모델 및 iPadOS 버전: ______ / 디지털 피아노 모델: ______ / 실행 방식(Safari·홈 화면 앱): ______

## 1단계: 설치
- [ ] GitHub Pages HTTPS 주소에 접속되고 앱 홈이 정상 표시된다.
- [ ] `곡 선택`, `연주하기`, `성장 기록`, `보호자 관리` 메뉴 전환이 된다.
- [ ] Safari에서 홈 화면 앱 추가가 된다.
- [ ] 홈 화면 앱에서 마이크 권한 요청이 표시된다.

## 2단계: 아이별 저장
- [ ] 아이 A를 등록한다.
- [ ] 아이 B를 등록한다.
- [ ] A의 연주 기록 저장 후 B로 전환하면 A 기록이 섞이지 않는다.
- [ ] 앱 종료 후 재실행 시 아이·기록이 유지된다.
- [ ] `JSON 백업`을 내려받고 다른 환경에서 `기록 복원`이 된다.
- [ ] 구버전 v0.2 저장소가 동일 사이트에 있으면 자동 가져오기가 된다(또는 JSON 복원).

## 3단계: 음악과 악보
- [ ] 곡 선택에 8곡이 표시된다.
- [ ] 미리듣기 시 음악이 처음부터 끝까지 합성 재생된다.
- [ ] 악보가 표시되고 재생 중 음표 위치가 이동한다.
- [ ] 계이름 표시/숨김이 작동한다.
- [ ] 느리게 60% / 원래 속도 / 빠르게 120%가 변한다.
- [ ] 곡 JSON 샘플을 내려받아 다른 ID로 수정 후 추가한다.

## 4단계: 실제 피아노 연주
- [ ] `한 음씩 따라 치기`를 시작하고 마이크가 켜진다.
- [ ] 디지털 피아노에서 `가운데 도(C4)`를 누르면 감지한 음이 도로 표시된다.
- [ ] 맞는 음을 치면 다음 계이름으로 넘어간다.
- [ ] 일부러 다른 음을 치면 오답 안내가 나온다.
- [ ] 반복 같은 음(도-도)도 별개 건반 입력으로 구분되는지 시험한다.
- [ ] 조용한 환경과 일반 거실 소음 환경에서 감도가 어떻게 다른지 확인한다.
- [ ] `혼자 연주`에서 4박 카운트 후 음정과 박자 판정이 기록된다.
- [ ] 헤드폰을 아이패드에 연결한 상태로 반주 모드를 시험한다(반주 혼입/오판정 여부 기록).
- [ ] 마이크 없이 화면 건반으로 시험한 기록이 별도로 표시된다.

## 5단계: 성장 및 운영
- [ ] 연주 종료 후 음정·박자·정답·누락·별이 표시된다.
- [ ] 7일 연습 그래프에 실제 연주 기록이 반영된다.
- [ ] 다른 아이로 변경하면 성장 차트도 변경된다.
- [ ] Wi-Fi 끈 상태에서 앱이 오프라인으로 재실행되는지 확인한다(실패 가능).
- [ ] GitHub에 파일 업데이트 후 기존 학습 기록이 유지되는지 확인한다.
