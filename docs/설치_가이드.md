# 피아노 레벨업 HOME v1.0 — GitHub 및 아이패드 설치 가이드

**목적:** Windows PC로 GitHub Pages에 등록하고, 아이패드 Safari 브라우저 또는 홈 화면 앱으로 사용. **GitHub에 압축 ZIP 파일을 그대로 업로드하는 방식은 작동하지 않습니다.** ZIP을 풀고 내용물을 업로드해야 합니다.

## A. 사전 준비

- GitHub 계정 (없으면 https://github.com/ 에서 생성)
- Windows PC와 인터넷, ZIP 압축을 해제할 프로그램
- 아이패드와 Safari 브라우저
- 스피커로 소리를 낼 수 있는 디지털 피아노(마이크 시험 시 주변 소음 최소화)
- 별도 구독형 유료 서버/음정 판정 서비스는 사용하지 않음

## B. 가장 쉬운 방법: GitHub 웹사이트에서 등록

1. 받은 `piano_levelup_HOME_v1.0_GitHub.zip`을 Windows PC에서 **압축 풀기** 합니다.
2. GitHub 사이트에서 **New repository**를 클릭합니다.
3. Repository name은 예를 들어 `piano-levelup-home`으로 지정하고 **Public**을 선택합니다. GitHub Pages가 외부에서 보이므로 개발 소스는 공개된다는 점에 주의하세요. 이 앱의 실제 아이별 학습 기록은 GitHub에 업로드하지 않습니다.
4. 저장소가 생성되면 `Add file` → `Upload files`를 선택합니다. 압축을 푼 폴더의 **내부 파일·폴더 전체**를 파일 업로드 화면에 드래그합니다(폴더 업로드가 브라우저에 따라 제한될 수 있으며, 그 경우 아래 GitHub Desktop 방식을 사용합니다).
5. **반드시 저장소 최상단에** `index.html`, `sw.js`, `manifest.webmanifest`가 있고 `js/`, `css/`, `assets/` 폴더가 같은 위치에 있어야 합니다. `piano_levelup_HOME_v1.0/index.html`처럼 한 단계 안쪽에 올라가면 루트 Pages 주소에서 열리지 않을 수 있습니다.
6. `Commit changes`를 클릭합니다.
7. 저장소의 `Settings` → 왼쪽 `Pages` → `Build and deployment`의 `Source`를 `Deploy from a branch`로 지정합니다.
8. Branch `main`, Folder `/(root)`를 선택하고 `Save`를 누릅니다.
9. 설정 화면에 표시된 **Visit site / 사이트 주소**에서 앱을 엽니다. 예시: `https://사용자아이디.github.io/piano-levelup-home/`. 사이트가 아직 열리지 않으면 GitHub Pages의 배포 상태를 확인합니다.

공식 참고: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## C. 폴더 업로드가 어려울 때: GitHub Desktop (Windows)

1. https://desktop.github.com/ 에서 GitHub Desktop을 설치하고 로그인합니다.
2. 웹사이트에서 만든 GitHub 저장소를 `File → Clone repository` 메뉴로 PC에 복제합니다.
3. Windows 탐색기로 ZIP에서 푼 `index.html`, `js/`, `css/`, `assets/`, `docs/`, `sw.js`, `manifest.webmanifest` 등 파일 전체를 **복제된 저장소 폴더의 최상위**에 복사합니다.
4. GitHub Desktop에서 변경사항을 확인하고 하단에 `v1.0 통합 앱 등록`이라고 작성하여 **Commit to main**을 선택합니다.
5. **Push origin**을 눌러 GitHub 서버에 반영합니다.
6. 위 B-7~B-9의 Pages 설정을 한 번 수행합니다.

**다음 버전 업데이트:** 새 파일을 같은 PC 복제 저장소에 덮어쓰기 → GitHub Desktop에서 Commit → Push origin. **ZIP 재업로드를 반복할 필요 없습니다.** 아이별 데이터는 로컬 저장소에 두되, 업데이트 전에 백업을 권장합니다.

## D. 아이패드에서 브라우저로 실행

1. 아이패드의 **Safari**에서 GitHub Pages HTTPS 주소를 엽니다.
2. 메뉴가 보이면 `보호자 관리` → 아이 이름 등록(최대 12명).
3. `곡 선택` → 원하는 곡 선택 → `♫ 노래 전체 듣기`로 미리 듣습니다.
4. `연주 시작` 버튼을 누르고 **마이크 허용**을 선택합니다.
5. 디지털 피아노 스피커에서 실제 음이 나도록 하고, 마이크 수음 상태(입력 표시)를 확인합니다.
6. `한 음씩 따라 치기`에서 가운데 도(C4)부터 음정을 확인합니다.
7. `혼자 연주` 모드는 4박 카운트 이후 연주하며, 박자와 음정 점수를 확인합니다.
8. `반주에 맞춰 연주`는 아이패드에 **헤드폰**을 연결하여 반주를 듣고, 디지털 피아노의 스피커 소리가 마이크에 들어오도록 구성합니다. 정확도는 현장 검증이 필요합니다.

## E. 아이패드 홈 화면에 앱 형태로 추가

1. Safari에서 GitHub Pages 앱 주소를 연 상태에서 `공유` 버튼을 누릅니다.
2. `홈 화면에 추가`를 선택합니다(목록에 없으면 더 보기/동작 편집에서 찾습니다).
3. `웹 앱으로 열기(Open as Web App)` 옵션이 보이면 **켭니다**.
4. `추가`를 선택한 다음 홈 화면에 나타난 피아노 레벨업 아이콘을 눌러 실행합니다.
5. 처음에 인터넷으로 캐시가 설치되면 재실행 시 일부 오프라인 동작을 기대할 수 있지만, iPadOS 저장소 정책에 따라 캐시가 삭제될 수 있어 오프라인 동작이 항상 보장되지는 않습니다.

Apple 공식 안내: https://support.apple.com/guide/ipad/bookmark-a-website-ipadc602b75b/ipados

### Safari와 홈 화면 앱 기록 주의

브라우저 접속과 홈 화면 웹앱은 iPadOS 상태/설정에 따라 저장 영역이 서로 다를 수 있습니다. 처음부터 한 방법을 선택해 꾸준히 사용하고, 장소/설치 방법을 바꾸기 전 **기존 사용 위치에서 JSON 백업**을 만든 뒤 새 위치에서 **JSON 복원**하세요.

## F. 오프라인 사용 및 업데이트

- 최초 사용 시 인터넷 연결을 유지하고 앱 화면을 열어 캐시가 생성되도록 합니다.
- 비행기 모드에서 앱을 재실행해 동작 여부를 점검합니다. 실패하면 Wi-Fi를 연결해 다시 실행합니다.
- GitHub에 수정한 파일을 업로드하면 다음 온라인 접속 중 새 서비스워커 캐시가 설치될 수 있습니다. 계속 이전 화면이 보이면 앱을 종료·재실행하거나 온라인 상태에서 새로고침합니다.
- 버전별 `sw.js`의 캐시 이름을 바꿔야 구버전 코드가 남지 않습니다.
- **GitHub 배포 업데이트만으로 아이별 기록이 GitHub 서버에 이동하거나 동기화되지 않습니다.** 프로필과 기록은 기기 내부에 남습니다.

## G. 오류 시 확인

| 증상 | 확인 사항 |
|---|---|
| 404 오류 | `index.html` 저장소 루트 여부, Pages 설정 `main` `/(root)`, 배포 완료 상태 |
| 화면만 나오고 음악 없음 | 아이패드 볼륨/무음 설정, `노래 전체 듣기`를 직접 눌렀는지 |
| 마이크 불가 | HTTPS 주소인지, Safari 마이크 권한 허용 여부, 다른 앱의 마이크 점유, iPadOS 설정 |
| 음정 오인식 | 조용한 장소·디지털 피아노 볼륨·마이크 감도 조정, 한 음씩 느리게 연주, 반주 소리 차단 |
| 화면 건반으로만 기록 | 마이크가 권한 거부된 경우 화면 시뮬레이션 테스트로 분류됨 |
| 이전 기록 없음 | 홈 화면 앱과 Safari 저장소 차이, 다른 URL(origin) 접속 여부, JSON 복원 필요 |
| 앱 오프라인 안 됨 | 최초 접속 캐시 형성 여부, 저장공간 여유, 삭제된 웹사이트 데이터 여부 |

## H. 앞으로 실제 정확도 고도화

이번 PWA는 마이크 단음 판정까지 구현한 베타입니다. 연주 박자·음 길이·양손/화음·페달까지 정밀 평가하려면 디지털 피아노 제조사와 모델명 확인 후 **iPad 네이티브 앱(Core MIDI)** 방식이 더 적합합니다. Safari에서는 Web MIDI를 사용할 수 없습니다.
