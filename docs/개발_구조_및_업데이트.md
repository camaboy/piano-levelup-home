# 프로그램 구조 및 차기 업데이트 개발 기준

## 관리 원칙

- 이 ZIP의 `index.html`이 GitHub Pages 사이트 시작 파일이다. **ZIP 자체를 GitHub 리포지토리에 올리면 웹앱은 실행되지 않는다.**
- 디지털 피아노 + iPad Safari 마이크 단음 인식, 한 기기에서 최대 12명 개인별 기록, 가정용 구독료 없는 운영이 기본 조건이다.
- 버전 업데이트 때 로컬저장소 `piano_levelup_home_v1` 키를 유지해야 한다. v0.2 읽기 전용 마이그레이션 키는 `piano_levelup_home_v02`.
- 서비스워커 수정 때 `sw.js` 캐시 이름을 변경하고 업데이트를 시험한다.
- 새 곡은 `js/songs.js`의 BUILTIN_SONGS 배열에 더하거나 보호자 화면에서 JSON을 추가한다. 음악의 음표·박자 데이터가 합성음 재생/오선지/채점의 단일 데이터 원천이다.
- 개인정보/실제 연주 마이크 원본은 GitHub나 외부 서버에 업로드하지 않는다.
- UI/가사/곡 관련 저작권 주의. 외부 상용 MP3/악보는 라이선스 확인 후 추가한다.

## 모듈 현황

| 파일 | 담당 기능 | 업데이트 예시 |
|---|---|---|
| `index.html` | 화면 골격/접근성 | 새로운 메뉴, 버튼 |
| `css/app.css` | 아이패드 레이아웃·색상·가로/세로 모드 | 색상, 디자인 변경 |
| `js/app.js` | 화면·연주 세션 UI·데이터 연결 | 학습 화면, 결과·관리 메뉴 |
| `js/audio.js` | 멜로디/반주 합성, 마이크 단음 감지 | 연주 감지 고도화 |
| `js/scoring.js` | 단음/박자 비교, 결과 점수 | 정렬·타이밍·연주 성취도 산출 |
| `js/songs.js` | 8개 곡·곡 JSON 검증 | 노래 추가, 메타데이터 확장 |
| `js/store.js` | 개인별 기록·v0.2 마이그레이션·백업 | 장기 통계·DB 확장 |
| `sw.js` | 오프라인 캐시·업데이트 | 새로운 파일 캐시, 버전 갱신 |
| `docs` | 설치, QA, 개발 기록 | 협업 및 업데이트 이력 |

## 기능 상태(2026-11-19)

**통합 구현**: 아이별 관리, 내장 곡 목록·검색, 합성 음악 전체 미리듣기, 오선지/계이름, 단음 마이크 판정, 초보 단계 학습, 4박 카운트+박자 점수, 단순 코드 반주 합성, 기본 성장 통계, 7일 연습 그래프, JSON 곡 추가, JSON 기록 백업·복원, PWA 홈화면, 오프라인 캐시, v0.2 기존 기록 이관.

**실험·정확도 미보증**: 반주와 동시에 마이크 실연주 분리, 반복음 정밀 타건 인식, 방·마이크 환경별 판정 정확도, 오프라인 캐시 유지, 실제 아이패드 설치/권한 동작.

**미구현/정밀 평가 제외**: 화음·양손 다성부 실시간 판정, 페달 평가, 정확한 음 길이 평가, 실제 MP3 녹음 반주, USB MIDI 장치에서 Safari로 바로 연주 입력, Mac에서 Xcode 빌드되는 iPad 네이티브 IPA, 백엔드 자동 동기화. 이러한 기능은 이 v1.0 통합 **시험판**에 작동하는 기능으로 표시하지 않는다.

## 음정과 박자 채점

- `한 음씩`: 현재 목표 건반과 감지 건반이 같을 때 진행; 잘못 누르면 오류 기록; 순서·음정 중심 점수.
- `혼자 연주`, `반주`: 4박 준비 후 음정과 시작 시점이 허용 오차 내 일치하는 음을 정답 처리; 놓친 음과 잘못된 음을 별도로 기록.
- 화면 건반으로 입력된 시험 기록은 별·레벨 해제에 반영하지 않으며 실제 연주 성장 통계와 분리한다.
- 박자 판정은 타이밍 오차와 빠짐을 반영한 **시작 타이밍 평가**이며 음 지속 길이(롱톤) 정확도는 아니다.
- 음정 점수·박자 점수는 정해진 공식에 따라 계산한 시험판 지표이며 실제 교육 측정으로 검증되지 않았다.
- 소리가 여러 음 겹치는 경우 최적 음 하나를 추정하여 부정확할 수 있다.

## GitHub 업데이트 예시

1. `js/songs.js`만 바꾼 경우도 `sw.js` 캐시 버전을 올린다.
2. GitHub Desktop에서 Commit + Push.
3. 아이패드 앱에 인터넷을 연결하고 다시 열어 새 버전을 반영한다.
4. 우선 ① 기존 아이별 데이터 ② 음악 재생 ③ 마이크 감지 ④ 오프라인을 테스트한다.
5. 업데이트 전 아이별 JSON 기록을 보호자가 백업한다.
