# 피아노 레벨업 HOME v1.0 통합 시험판

> iPad Safari / GitHub Pages 배포용 · 디지털 피아노 소리 인식 · 가족용 다중 프로필 · 오프라인 캐시 지원 시도

## 바로 시작하기

1. 이 폴더의 **내용물 전체**(`index.html`, `js/`, `css/`, `assets/`, `manifest.webmanifest`, `sw.js`, `docs/` 포함)를 GitHub 리포지토리 최상위에 업로드합니다.
2. GitHub → Settings → Pages → **Deploy from a branch** → `main` → `/(root)` → Save를 선택합니다.
3. Pages에 표시되는 HTTPS 주소를 **아이패드 Safari**에서 열고, 공유 → 홈 화면에 추가 → 웹 앱으로 열기 → 추가를 선택합니다.
4. 보호자 관리에서 아이를 등록합니다. 곡을 선택하고, 전체 미리듣기를 한 뒤 연주를 시작해 마이크 권한을 허용합니다.
5. 학습 기록을 정기적으로 **JSON 백업**합니다.

자세한 안내: [docs/설치_가이드.md](docs/설치_가이드.md) · [docs/점검_체크리스트.md](docs/점검_체크리스트.md)

## 구성

- **홈**: 아이별 진행 상황, 추천 곡
- **곡 선택**: 총 8개 기본 곡, 난이도/장르 검색, 자체 Web Audio 악기 연주(외부 음원 없음)
- **연주하기**: 오선지와 계이름, 건반 표시, 곡 전체 재생, 3가지 연습 모드
  - 음표마다 멈춰서 따라 치기
  - 전체를 미리 듣고 혼자 치며 음정·타이밍 판정
  - 반주를 들으면서 연주(헤드폰 사용 시도, **실험 기능**)
- **성장 기록**: 음정 점수/박자 점수/누락/오류, 7일 통계, 아이별 별/레벨
- **보호자 관리**: 최대 12명, 감도 설정, JSON 기록 백업/복원, 직접 만든 곡 JSON 등록
- **버전 호환**: 동일 사이트(origin)에 저장된 v0.2 학습 기록(`piano_levelup_home_v02`)을 자동 가져오는 기능

## 기술 구조

- `index.html` UI, `css/app.css` 스타일
- `js/app.js` 화면과 연습 상태 관리
- `js/audio.js` Web Audio 음악 합성·마이크 단음 감지
- `js/scoring.js` 단계형/실시간 비교·결과 계산
- `js/songs.js` 곡 라이브러리와 추가곡 데이터 검증
- `js/store.js` 아이별 로컬 기록·마이그레이션·백업
- `manifest.webmanifest`, `sw.js` 홈 화면 실행·오프라인 캐시
- `assets/` 앱 아이콘
- `docs/` 설치 안내·점검표·개발 기준·업데이트 안내

## 중요한 제한 사항

- iPad Safari PWA에서 Web MIDI가 지원되지 않으므로 **마이크 단음 판정**을 사용합니다. 미세한 음정·페달·화음·양손/음 길이는 정확히 판정하지 못합니다.
- 반주가 스피커로 흘러나오면 마이크가 반주를 피아노 연주로 오인할 수 있습니다. **아이패드 헤드폰으로 반주 듣기**, 디지털 피아노 스피커로 실제 건반 소리를 내는 배치가 필요합니다. 정확도 보장 불가.
- 모든 음악은 저장된 음표 데이터로 **합성 연주**됩니다. 실제 녹음된 MP3나 온라인 음원 스트리밍 기능은 없습니다.
- 리포지토리에 실제 아이별 기록은 올라가지 않습니다. 저장 장소는 현재 Safari/PWA의 로컬 저장소이고 Safari, 홈 화면 웹앱, 다른 도메인에서 서로 기록이 분리될 수 있습니다.
- GitHub Pages에 소스를 올린 것은 앱스토어 앱 설치가 아닙니다. 인터넷 연결 상태에서 최초 실행해야 하며, 오프라인 캐시는 기기 상태에 따라 유지되지 않을 수 있습니다.
- 이 릴리스는 **v1.0 통합 베타**이며 iPad 실기 테스트 전입니다.
