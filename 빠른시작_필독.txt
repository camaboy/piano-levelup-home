피아노 레벨업 HOME v1.0 통합 베타 - 빠른 설치

1) ZIP 압축을 해제합니다.
2) GitHub의 공개 저장소(piano-levelup-home 예시)에 압축 해제된 파일/폴더 '내용물'을 전부 업로드합니다.
   ※ ZIP 파일 자체를 GitHub에 넣어서는 프로그램이 작동하지 않습니다.
   ※ 최상위에 index.html 이 있어야 합니다.
3) GitHub 저장소 → Settings → Pages → Deploy from a branch → main / (root) → Save
4) 표시된 HTTPS 사이트 주소를 iPad Safari로 엽니다.
5) Safari의 공유 → 홈 화면에 추가 → 웹 앱으로 열기 → 추가
6) 보호자 관리 → 아이 등록 → 곡 선택 → 미리듣기 → 연주 시작(마이크 허용)

중요: 아이별 기록은 GitHub가 아니라 아이패드 내부에 저장됩니다.
업데이트/기기 변경 전 보호자 관리 → JSON 백업을 권장합니다.
반주 동시 연주 점수는 시험용입니다. iPad 헤드폰을 사용해 반주를 듣고
실제 디지털 피아노 소리는 피아노 스피커에서 나오게 하세요.
